# 一括納付明細書チェックリスト作成システム

気高電機株式会社の経理業務向け、PDFから一括納付明細書チェックリストを自動生成するWebアプリケーションです。仕様書 `一括納付明細書チェックリスト作成システム_仕様書_v1.0.docx` に準拠して実装しています。

## 主な機能

| ID  | 機能 | 状態 |
| --- | ---- | ---- |
| F-01 | 複数PDFの一括アップロード | ✅ |
| F-02 | PDF種別の自動分類(納付番号通知 / 一括納付用明細書 / 書類送付案内状 / 輸入許可通知書 / 諸掛請求書 / 延納マルチ) | ✅ |
| F-03 | 代理人コードによる通関業者グルーピング | ✅ |
| F-04 | 納付番号・受入科目・税額・輸入申告番号の抽出 | ✅ |
| F-05 | 突合チェック(明細合計 vs 納付番号通知 / 一括納付用明細書合計 vs 納付番号通知) | ✅ |
| F-06 | Markdown出力(画面プレビュー / ダウンロード) | ✅ |
| F-07 | Excel貼付け用 TSV 出力(セクション別 + 一括) | ✅ |
| F-08 | 諸掛請求書から許可通知書ページのみ抽出 | ✅ |
| F-09 | 一括納付明細書順に許可通知書を並び替えてPDF生成 | ✅ |
| F-10 | 仕入書番号(下5桁)対応表生成 | ✅ |
| F-11 | OCRによる延納マルチ納付書解析 | ⏳(画像PDFの場合は次フェーズ) |
| F-12 | 1社単位の処理 | ✅(分類で代理人ごとに自動分割) |

## 動作環境

- Python 3.10+
- 仕様書 §2.1 のスタックに準拠(FastAPI + PyMuPDF)

## セットアップ

```bash
pip install -r app/backend/requirements.txt
```

## 起動

```bash
python -m app.run --host 0.0.0.0 --port 8000
```

ブラウザで `http://localhost:8000/` を開き、PDFをドラッグ&ドロップしてください。

### API一覧 (仕様書 §5.1 と対応)

| メソッド | パス | 用途 |
| --- | --- | --- |
| `GET`  | `/api/v1/health` | ヘルスチェック |
| `POST` | `/api/v1/checklist` | PDFアップロード → チェックリスト生成 |
| `GET`  | `/api/v1/checklist/{sid}/markdown` | Markdown ダウンロード |
| `GET`  | `/api/v1/checklist/{sid}/tsv?section=...` | TSV ダウンロード(`attached_files`/`company_page_counts`/`company_details` または無指定で全体) |
| `GET`  | `/api/v1/checklist/{sid}/permits.pdf` | 並び替え済み許可通知書PDF |
| `DELETE` | `/api/v1/checklist/{sid}` | セッション削除 |

## セキュリティ・運用上の注意 (仕様書 §8.2 / §8.3 抜粋)

- アップロードされたPDFはサーバーの一時ディレクトリに保存され、24時間後または明示的なリセット操作で自動削除されます。永続化は行いません。
- 本番運用時はHTTPS終端と社内SSO/Basic認証を前段で必ず設定してください。
- ログにPII(輸入者名・住所・税額の詳細値)を出力しないよう、追加機能を実装する際もログレベルに注意してください。

## 既知の制約 (仕様書 §10 抜粋)

- 一部のスキャン許可通知書はOCR品質により仕入書番号(B欄)が空欄として表記されることがあります。`(記載なし)` と表示されるので手動確認してください。
- 月末申告分(例: 3/26申告)の許可通知書は、当月の諸掛請求書に含まれない場合があります。`(当月請求書に未掲載)` と表示します。
- 延納マルチ納付書(画像PDF)のOCRは Phase 3 の対応範囲です(現状: 種別判定のみ)。
